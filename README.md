#📊 StayVista-Airbnb-Performance-Dashboard

This project is an interactive Power BI dashboard built using Airbnb dataset to analyze listings, hosts, reviews, property types, and market growth trends.

## 🎯 Project Objectives

- Analyze Airbnb listings and host performance  
- Identify trends in reviews and customer engagement  
- Compare property types and room categories  
- Evaluate listing growth over time  
- Provide actionable business insights through visual analytics  

---

## 📈 Key Metrics Used

- Total Listings  
- Total Hosts  
- Total Cities  
- Total Reviews  
- Reviews per Reviewer  
- Verified Host %  
- Monthly Review %  
- Cumulative Reviewers  

---

## 📊 Dashboard Features

✔ Interactive KPI cards for quick monitoring  
✔ Trend analysis by month/year  
✔ Property type comparison  
✔ Review growth visualization  
✔ Dynamic filters for city, room type, year  
✔ Host verification insights  

---

## 🛠 Tools & Technologies

- Power BI Desktop  
- DAX (Data Analysis Expressions)  
- Power Query  
- Data Modeling  
- Data Cleaning  

---

## 📂 Dataset

The dataset contains Airbnb business data including:

- Listing information  
- Host details  
- Review data  
- Property type  
- City data  
- Pricing information  
- Dates & timeline records  

---

## 💡 Key Business Insights

- Entire home listings dominate the market  
- Verified hosts receive higher engagement  
- Review growth increased after expansion years  
- Some cities generate more listings than others  
- Seasonal trends affect review activity
